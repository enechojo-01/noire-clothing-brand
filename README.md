# NOIRÉ — Luxury Clothing Brand

A responsive luxury fashion storefront concept using **Next.js + React + Tailwind CSS + Framer Motion**.

## Brand system
- Black Olive `#3D402F`
- Pearl `#FCF9D8`
- Lilac `#C99FCD`
- Display font: Quffer (drop the licensed `Quffer.woff2` into `public/fonts/`)

## Included interactions
- Cinematic scroll-reactive hero
- Responsive navigation/mobile menu
- Editorial product gallery
- Product detail modal with spring animation
- Functional local bag counter
- Smooth anchor navigation
- Responsive mobile layouts

## 21st.dev direction
The gallery/hero interaction direction was informed by 21st.dev's current cinematic product-scroll patterns. The 21st registry is copy-paste based rather than a conventional npm dependency, so this project keeps the implementation local and theme-specific instead of pretending 21st is an installed runtime package.

21st reference: https://21st.dev/@a.karamooz3232/components/cinematic-product-scroll-section

## Run
npm install
npm run dev
